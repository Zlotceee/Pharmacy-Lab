# Pharmacy Lam — бот для домашней аптечки

Telegram-бот, который хранит список лекарств и следит за сроками годности.

**Возможности:** добавление лекарства по шагам (название, описание, срок годности, количество), список лекарств с карточкой каждого, отчёт по срокам годности (просрочено / истекает в ближайшие 30 дней / в порядке), удаление одного лекарства или всех просроченных сразу.

**Стек:** Python, pyTelegramBotAPI, SQLite.

## Устройство

- `database.py` — работа с SQLite: таблица `medicines`, добавление, выборка и удаление записей с привязкой к пользователю.
- `bot.py` — команды, клавиатуры, пошаговый диалог добавления и обработка инлайн-кнопок.
